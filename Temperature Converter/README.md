# Temperature Converter

A responsive temperature conversion web application built with HTML, CSS, and JavaScript.

## Features
- Convert Celsius, Fahrenheit, and Kelvin.
- Real-time conversion when the Convert button is clicked.
- Input validation.
- Absolute zero temperature validation.
- Reset button.
- Responsive design.

## Technologies Used
- HTML5
- CSS3
- JavaScript
